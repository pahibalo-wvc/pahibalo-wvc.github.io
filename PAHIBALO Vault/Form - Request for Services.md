# Request for Services

Back to [[Home]]

> [!summary] In short
> Request printing (reproduction), security or janitorial help for an activity.

## Who needs it and when
Orgs and units running an activity. The facilities permit says security, janitorial and IT help need their own form. This is that form for printing, security and janitorial. Which form covers IT help: (unknown).

## Steps
1. Tick the service: reproduction, security or janitorial.
2. For reproduction, write the number of copies and sheets per set.
3. Write the dates and time needed, the purpose and the details.
4. Sign as the requisitioner and write your position.
5. Get the signatures below.
6. When the job is done, the end user signs to confirm it was finished (or explains why it could not be).

## Who signs
1. Division Chief (recommends approval)
2. FAD Chief (approves or disapproves)
3. End user (acknowledges the service)

## Where to submit
The FAD Officer.
