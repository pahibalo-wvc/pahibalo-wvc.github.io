# Grading System

Back to [[Home]]

> [!summary] In short
> Grades run from 1.00 (best) to 5.00. Each quarter after the first blends with the last.

## The scale (2018 handbook)
| Score | Grade | Meaning |
|---|---|---|
| 96-100 | 1.00 | Excellent |
| 90-95.99 | 1.25 | Very Good |
| 84-89.99 | 1.50 | Very Good |
| 78-83.99 | 1.75 | Good |
| 72-77.99 | 2.00 | Good |
| 66-71.99 | 2.25 | Satisfactory |
| 60-65.99 | 2.50 | Satisfactory |
| 55-59.99 | 2.75 | Fair |
| 50-54.99 | 3.00 | Fair |
| 40-49.99 | 4.00 | Failed on condition |
| below 40 | 5.00 | Failed |

3.00 is the lowest grade above "failed on condition" (read from the table).

## Cumulative grading
From the 2nd quarter on: quarter grade = (tentative grade × 2 + previous grade) ÷ 3.

## GWA
Your general weighted average weights each subject by its units (see [[Guide - Curriculum and Units]]). Try the [[Tool - GWA Calculator]].
