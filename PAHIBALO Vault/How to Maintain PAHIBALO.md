# How to Maintain PAHIBALO

Back to [[Home]]

Written for non-coders. Works with any editing method (D26 is deferred).

## Add a page
1. Copy a note from the `Templates` folder.
2. Rename it with the naming rule: `Form - …`, `Org - …`, `Office - …`, `Comp - …`, `Guide - …`, `Kit - …`, `Dorm - …`, `Commute - From to To`, `Story - Name - Topic`.
3. Fill every property. Unknown = "(unknown)". Never guess.
4. Keep `Back to [[Home]]` at the top.

## Update a page
Change the facts, then set `last_updated` to today and `source` to where you checked.

## Add an alias
Add it to the note's `aliases` list. The [[Alias Table]] updates itself.

## Rename a tab
Change the hub note's title and the site menu. (Site steps: decided at build.)

## Writing rules for site text
- Never invent facts, dates or sources. If something is not known, write "(unknown)".
- Plain student voice in English: short sentences, no contractions, no exclamation marks, no rhetorical questions.
- No staff, officer or student names on any page.
- Notes only editors should see go between `%%` marks; the site hides them.
- Every note keeps its frontmatter, `Back to [[Home]]`, a `source` and a `last_updated` date.
- Photos: blur or crop every clear face, credit every photo in [[Credits]], and treat posters and signs as information only. If a page has fewer photos than its area needs after a real search, log it in [[Photo Exceptions]].
- Forms have no pictures; their templates stay on Google Drive.

## Yearly
Check [[Review Calendar]] and name next year's maintainers. Changes are recorded in the site's Git history.
