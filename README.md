# PAHIBALO WVC

A student-made guide to PSHS Western Visayas Campus: forms, offices, orgs, events, competitions and more, written by the PAHIBALO org. This is not an official school site.

- `PAHIBALO Vault/`: the content, one Markdown note per page (an Obsidian vault). Start with `Home.md` and `How to Maintain PAHIBALO.md`.
- `Site/`: the code that turns the vault into the website (`build.py`, `check.py`, templates and assets). See `Site/README.md`.

Every change is built and checked on GitHub before it goes live. To fix something on the site, open its note, edit it and propose the change; a PAHIBALO maintainer approves it.
